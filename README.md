# 🚀 PROMPT COMPLETO: LANDING PAGE IMERSÃO EXECUÇÃO TOTAL

## 📋 BRIEFING EXECUTIVO

Você vai criar uma **landing page de alta conversão** para a "Imersão Execução Total", um evento de 2 dias focado em ensinar o "Protocolo IA" para empresários e CEOs. O objetivo é converter visitantes em compradores de tickets (R$ 47) através de um fluxo otimizado: CTA → Modal WhatsApp → Checkout.

**Público-alvo**: Empresários, donos de empresa e CEOs com faturamento entre R$ 2 mi e R$ 50 mi, que buscam resultado prático, velocidade e autonomia operacional.

**Ticket**: R$ 47 (baixa fricção de compra)

**Diferencial**: Implementação prática vs. teoria pura.

---

## 🎨 IDENTIDADE VISUAL & DESIGN SYSTEM

### Paleta de Cores
- **Fundo Principal**: Preto profundo (#000000 ou #121212)
- **Fundo Secundário**: Cinza muito escuro (#1a1a1a)
- **Texto Principal**: Branco puro (#FFFFFF)
- **Texto Secundário**: Cinza claro (#CCCCCC ou #999999)
- **Accent Primário**: Laranja neon vibrante (#FF6600) — usado em CTAs, ícones, highlights
- **Borders**: Cinza escuro com baixa opacidade (#333333 com 30% opacity)

### Tipografia
- **Font Family**: Sans-serif moderna (Inter, Poppins ou similar)
- **Headlines (H1)**: Branco, bold (700), 32px-48px (desktop), 24px-32px (mobile)
- **Subheadlines (H2)**: Branco, weight 600, 20px-28px (desktop), 18px-24px (mobile)
- **Body Text**: Cinza claro (#CCCCCC), weight 400, 14px-16px
- **Small Text**: Cinza médio (#999999), weight 400, 12px-14px

### Componentes UI
- **Cards**: Fundo #1a1a1a, borda sutil (#333333), border-radius 8-12px, padding 24px-32px
- **Botões CTA**: Fundo #FF6600, texto branco, padding 12px 24px, border-radius 8px, hover: #FF7722
- **Ícones**: Laranja (#FF6600) ou azul (#0099FF), tamanho 24px-32px
- **Spacing**: 24px-32px (padding), 16px-24px (margin), 48px-64px (section gaps)

### Responsividade
- **Mobile**: 320px-480px
- **Tablet**: 481px-768px
- **Desktop**: 769px+
- **Mobile-first approach**: Começar pelo mobile e escalar para desktop

## 🔄 MODAL WHATSAPP (FLUXO DE CONVERSÃO)

### Trigger
- Usuário clica em qualquer botão CTA ("Garanta sua vaga", "Quero Ativar o Protocolo IA", etc.)

### Modal Estrutura

**Headline:**
```
Antes de prosseguir, deixe seu WhatsApp para receber os detalhes da imersão!
```

**Campos:**
1. **DDD (obrigatório)**: Dropdown com DDDs brasileiros (11, 21, 31, 85, etc.)
2. **WhatsApp (obrigatório)**: Input de telefone com máscara (99999-9999)

**Botões:**
- **Primário**: "Continuar para Checkout" (Laranja #FF6600)
- **Secundário**: "Cancelar" (Cinza)

### Validação
- DDD: Obrigatório, deve ser selecionado
- WhatsApp: Obrigatório, deve ter 8-9 dígitos

### Ação ao Submeter
1. Validar campos
2. Armazenar dados (localStorage ou backend)
3. Redirecionar para URL de checkout (a ser definida)

### Estilo do Modal
- Fundo: Overlay escuro com 80% opacity
- Card: Fundo #1a1a1a, borda laranja, border-radius 12px
- Width: 400px (desktop), 90vw (mobile)
- Padding: 32px
- Headline: Branco, 20px, bold
- Labels: Cinza claro, 14px
- Inputs: Fundo #0a0a0a, borda #333333, texto branco, padding 12px
